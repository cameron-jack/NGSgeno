Welcome to the API/coding documentation for the NGS Genotyping pipeline project for v2.04.000. Currently type annotations are mostly missing, largely due to the project beginning with a much earlier version of Python. This document with prepared with the help of pydocgen.py, which itself was generated using Claude Code AI.


The main function is found in ngsgeno.py.

Streamlit is responsible for the web interface, and all GUI elements (forward-facing code) are located in:

  • ngsgeno.py - Main application logic
  • stage_load.py - First pipeline stage
  • stage_nimbus.py - Nimbus pipeline stage
  • stage_primers.py - Primer PCR stage
  • stage_index.py - Indexing PCR stage
  • stage_miseq.py - MiSeq sequencing stage
  • stage_alleles.py - Allele calling stage
  • stage_report.py - Reporting stage
  • display_alignments.py - Alignment display functionality for reporting amplicons
  • display_components.py - widgets that calculate and display
  • load_data.py - Data loading widgets
  • stutil.py - Streamlit utility functions, messages, CSS

Input handling is done through a load queue in parse.py, which also handles the parsing of inputs.

Output handling is done through a results queue in generate.py, though it needs unification. Outputs are first generated as "pending_" with transaction.py until they are declared safe to save.

Multiple sequence alignment is handled in match.py, and alignment of individual sequences is done in ngs_match.py.
