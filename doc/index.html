NGS Genotyping Pipeline Documentation

This contains all the documentation for the NGS Genotyping Pipeline, NGSG Retype, and NGSG Reference, as well as how to get started using the NGSG Explorer web service v2.04.000.


Software installation

To install the pipeline and additional tools (Retype and Reference), follow these steps:

  1. Clone the repository from GitHub. $ git clone https://github.com/cameron-jack/NGSgeno.git
  2. Create a new virtual environment. $ python -m venv ngsgeno_env
  3. Activate the virtual environment. $ source ngsgeno_env/bin/activate
  4. Install Python v3.12 and the required dependencies using pip. $ python -m pip install .
  5. Create desktop shortcuts to the run scripts: Run_NGSgeno.bat, run_reference.bat, andrun_retype.bat
  6. Double click your shortcut to run the application.

Using the pipeline

New users should read:

  • the glossary to familiarise themselves with the terms used in this pipeline
  • the start page that they will see when they first start the application
  • the new experiment documentation to understand the standard features of the interface.

The NGS Genotyping pipeline is composed of several stages:

  1. Load samples, consumables, amplicon plates
  2. Hamilton Nimbus plate combining (96 to 384 well)
  3. Primer selection and PCR step 1
  4. Indexing and PCR step 2
  5. Miseq sequencing
  6. Allele matching
  7. Reporting

Additional software tools

There are three additional stand-alone tools that have been integrated with v2.04.000 of the pipeline:

  • NGSG Version Select - checks for new pipeline versions and allows the user to choose which one they want to be active
  • NGSG Retype - for finding failed assay runs and building a new custom manifest (384 well) to rerun (retype) these assays
  • NGSG Reference - which take an Excel-based reference file and converts it to FASTA, while also looking for forbidden characters and formating issues
